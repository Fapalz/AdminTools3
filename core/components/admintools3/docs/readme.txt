# AdminTools3 1.0.0

Дополнительные инструменты для менеджера MODX Revolution 3. После установки обновите страницу менеджера. Плагин **AdminTools3** должен быть включён в категории «AdminTools3».

## Как пользоваться

- **Избранное.** Откройте вкладку «Элементы». Наведите курсор на шаблон, TV, чанк, сниппет или плагин и нажмите звезду справа от названия. Кнопка со звездой над разделом «Шаблоны» показывает только избранные элементы сразу во всех разделах; повторное нажатие возвращает полный список.
- **История изменений.** Кнопка с часами рядом с избранным открывает список недавно изменённых элементов. В окне можно искать и открывать элементы.
- **События плагинов.** Кнопка списка в строке «Плагины» открывает таблицу плагинов по событиям. Там доступны поиск, включение и отключение плагинов и управление их привязками.
- **Заметки.** Откройте меню профиля и выберите «Заметки» под пунктом «Сообщения». Можно создавать личные и общие заметки, искать их, а также импортировать и экспортировать JSON. Личные заметки видны только своему автору.
- **Связанные ресурсы.** В редакторе шаблона вкладка «Ресурсы» показывает использующие его ресурсы. В редакторе ресурса доступна вкладка альтернативных прав доступа, если эта функция включена в настройках.
- **Внешний вид.** В системных настройках выберите пространство имён `admintools3`. Параметр `admintools3_theme` переключает тему (`default`, `dark`, `purple`). Через `admintools3_custom_css` и `admintools3_custom_js` можно подключить свои файлы для менеджера; несколько URL разделяются запятыми.

Там же включаются или отключаются отдельные функции: избранное, история элементов, заметки, интерфейс событий плагинов, альтернативные права, выборочная очистка кеша, блокировка менеджера и вход по ссылке. Поиск в TV с множественным выбором поддерживает русские названия вариантов.

## Обновление и удаление

Если на сайте был установлен AdminTools, первая установка переносит его настройки, заметки, права и пользовательские предпочтения. Исходные данные остаются в старом пакете. Для старой формы входа замените вызов `[[!adminLogin]]` на `[[!adminLogin3]]` перед удалением AdminTools.

При деинсталляции вариант MODX «Сохранение» оставляет данные AdminTools3 для повторной установки. Вариант «Деинсталлировать» удаляет его заметки, альтернативные права, настройки и пользовательские предпочтения. Данные прежнего AdminTools не затрагиваются.
